04 · Onboarding

FAQ & open questions

Questions a new person is likely to ask when they first encounter the system. Answers are limited to what the current documentation establishes.

Architecture

Is ATI Flow the same thing as the robot’s autonomy stack?

No. The documentation separates orchestration/product from low-level robot configuration, navigation and diagnostics.

Configuration

Why are Maps and Workflows separate?

Maps describe the spatial environment and movement rules. Workflows describe actions and transport behaviour.

State model

Does a robot under maintenance still count as available capacity?

It should be excluded from normal dispatch if maintenance is a real operational state, but the provided IA does not define the complete state machine.

Terminology

Is “taxi mode” an industry-standard AMR mode?

The current documentation does not establish that. “Taxi” is explicitly used as a mission pattern meaning on-demand, point-to-point transport.

Access

Who should see low-level robot diagnostics?

The current IA places Debug exclusively with the Solutions Architect (Configurator) role.
