Visual reference

Dashboard language

The supplied ATI Flow dashboard establishes the visual direction used for this documentation: white surfaces, fine grey borders, rounded cards, teal navigation accents, and green/red operational states. The documentation mirrors that hierarchy rather than introducing a separate brand language.

How to read the dashboard

  1. Start with system state: Is the fleet operating normally?
  2. Look for exceptions: Which robots, tasks or zones need attention?
  3. Understand impact: Is the issue isolated or affecting material flow?
  4. Act at the right layer: operational intervention belongs in Fleet Monitor/Robots; configuration belongs in Maps/Workflows/Setup; low-level diagnosis belongs in Debug.
