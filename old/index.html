ATI Flow · Documentation

The Material Orchestration System for Today’s Factory

A practical guide to understanding how ATI Flow turns factory material demand into coordinated robot movement — and how the people, maps, workflows, fleets and integrations fit together.

Start here. This documentation is designed for someone joining ATI who needs to understand the product before designing, building, configuring, supporting or operating it.

01 · Mental model

What is ATI Flow?

ATI Flow is ATI Robotics’ software layer for automated material orchestration. It sits between a factory’s material movement requirements and the robot fleet that executes those movements.

The core chain is: factory need → movement request → configured workflow → fleet coordination → robot execution on the floor.
