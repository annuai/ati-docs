term: VDA 5050
kind: jargon
simple: A standard way for a fleet control system and mobile robots to communicate with each other.
technical: An interface for exchanging job and status data between a central fleet control system and mobile robots. It is designed to allow heterogeneous fleets from different manufacturers to operate with a shared control system. VDA 5050 version 3.0.0, released in March 2026, also supports higher-autonomy mobile robots through concepts such as zones and path sharing.

note: VDA 5050 is a communication interface, not a safety standard and not the traffic-management logic itself. The current version is 3.0.0.
