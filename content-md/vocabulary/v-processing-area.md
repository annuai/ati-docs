term: Processing area
kind: term
simple: A configured part of a plant where the material, containers, workflows, devices and inventory for that operation are set up together.
technical: In AtiFLOW v2.0, a Processing Area is a plant-level configuration boundary. It contains machine details, linked stations, material and container configuration, workflows, device configuration and Processing Area inventory. Its system function is to segregate a relevant subset of Plant Master Data into a local material list for that operation.
