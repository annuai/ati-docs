HOW TO PASTE THIS INTO FIGJAM
1. Open a FigJam file, empty canvas.
2. For each cluster below: first copy just its ONE-LINE HEADER (the "===" line) and paste it onto the canvas by itself — FigJam turns a single pasted line into one sticky note; drag it to the top of an empty area and treat it as the cluster's title card (optionally recolor it, e.g. grey, to mark it as a header).
3. Then select all the note lines under that header (everything between it and the next "===" header) and paste them together just below/around the title card — FigJam converts a multi-line paste into one sticky note per line, auto-arranged in a grid. Drag that grid under its header.
4. Repeat per cluster, spacing each group apart on the canvas so the six clusters read as six visual zones.
5. Each note ends with "— [source]" in brackets — keep that in the paste; it's useful context on the sticky itself. If you'd rather have clean stickies with no source text, strip the "— [source]" suffix from each line before pasting.
